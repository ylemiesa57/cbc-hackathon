# CBC Hackathon — Landing Page

## Project
Next.js 16 (App Router), Tailwind CSS 4, TypeScript. Single-page sponsorship landing page for the Claude Builders Club Hackathon.

## Event
- **Event:** Claude Builders Club Hackathon
- **Date:** April 26, 2026
- **Venue:** MIT Media Lab, Floor 3 — Cambridge, MA
- **Expected attendees:** 100 MIT students
- **Contact:** claude@mit.edu

## About CBC
CBC provides MIT students with API credits, funding, and mentorship to build real AI projects outside the classroom. Backed by Anthropic. Past members have gone on to work at OpenAI, Anthropic, DeepMind, and other frontier AI labs.
